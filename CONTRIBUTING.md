# Contributing

1. Create a branch for one change.
2. Keep comments short and practical.
3. Do not remove third-party copyright or license notices.
4. Run `npm test` before opening a pull request.
5. Run `npm run build` and test Send and Receive over HTTPS.
6. Test at least one Android browser and one iPhone browser when changing the camera code.
7. Do not add a transfer mode unless it works with a real phone camera.
