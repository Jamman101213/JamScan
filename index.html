Clear feedback at every step

Automatic camera lock

The scanner tries several centered crops and remembers the best one after it finds the bordered square.

Start and end markers

Starting in the middle is handled safely. JamScan waits for the next start marker before accepting data.

Accessible alternative

The visual stream is not the only route. The same content can be shared as a keyboard-accessible .jscan file.
