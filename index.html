Screen to camera file transfer

Move files with light.

JamScan turns a file into an endless stream of standard QR codes. A second device can start scanning at any point and recover the file without a network connection between the devices.

SendChoose a file or text and display the animated QR stream. ReceiveUse a phone camera and rebuild the file from valid QR frames. Open .jscanVerify and preview a saved JamScan package.
JamScan 2.1. Open source under MIT. Optical engine adapted from Decimen Optical Transfer under MIT.
