Test a frame image

Select a screenshot containing one complete JamScan frame. The decoder tries several centered crop sizes.

  • Data from the middle of a loop is ignored until a start marker appears.
  • Sequence gaps are counted as missed flashes.
  • Missing data stays listed and is filled during later loops.
  • Every frame has a CRC check and the final package is verified again.
  • The recovered item stays hidden until the content warning is accepted.
