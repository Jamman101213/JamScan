Moving high-contrast pattern

The JamScan square changes between black-and-white frames.

Do not start the stream for anyone who is sensitive to flashing or changing patterns. Keep the selected rate at 3 frames per second or lower. Stop immediately if anyone feels unwell.

For a nonvisual and nonflashing transfer, use the Save .jscan button and send the file directly.
